# Учёт ремонтов мототехники

Сайт для учёта ремонтов: общая сумма, запчасти, чистый доход, время, таблица по числам месяца, записи клиентов, выгрузка и загрузка Excel. Работает бесплатно на GitHub Pages, на телефоне ставится как приложение и работает без интернета.

**Открыть:** https://romchill.github.io/moto-uchet/

## Что умеет

- **Сегодня** — быстрая запись одной строкой (`5000 1200 2:30 Yamaha R6 цепь`) или форма-калькулятор, ремонты за день с итогами, кто из клиентов записан на сегодня, итоги недели.
- **Месяц** — итоги и таблица по числам; нажми на день, чтобы исправить его ремонты. Выгрузка в Excel.
- **Записи** — запись клиента на день и время, «✅ Сделано» сразу переносит ремонт в учёт, перенос, отмена, добавление в календарь телефона (он и напоминает).
- **Ещё** — Excel (выгрузка, загрузка с защитой от повторов, пустой шаблон), резервная копия, установка на телефон.

## Где хранятся данные

Только в браузере на устройстве (localStorage). На сервер ничего не отправляется. Чтобы перенести данные на другой телефон — «Ещё» → «Сохранить копию», потом на новом телефоне «Восстановить из копии».

## Как обновлять

Это обычные статические файлы, сборка не нужна. После любых изменений подними номер версии `CACHE` в `sw.js` — иначе установленные на телефоны копии продолжат открывать старую версию.

Тесты логики лежат вне репозитория; `core.js` и `excel.js` можно подключить в Node через `require`.

Excel читается и пишется библиотекой [SheetJS](https://sheetjs.com) 0.20.3 (`vendor/`, лицензия Apache 2.0 — `vendor/LICENSE-sheetjs.txt`).
